# Controle de Hortaliças

## Registro de Perdas

Sistema web desenvolvido para auxiliar no registro e controle de perdas ocorridas na produção de hortaliças.

### Aplicação online

Acesse o sistema:

https://gleicielly.pythonanywhere.com

### Funcionalidades

- Cadastro de perdas
- Listagem das perdas registradas
- Edição de registros
- Exclusão de registros
- Registro de produto, quantidade, data e motivo da perda

### Tecnologias utilizadas

- Python
- Flask
- HTML
- CSS
- SQLite
- Git e GitHub
- PythonAnywhere
